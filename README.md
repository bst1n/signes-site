# signes-site

Pages publiques de **Signes** : aide, conditions d'utilisation et politique de
confidentialité, en français et en anglais.

Ce dépôt est public parce que l'App Store exige que la politique de
confidentialité et la page de support soient accessibles à une URL publique.
Il ne contient que du HTML statique.

Les textes ne sont pas écrits ici : ils sont **générés** depuis la source de
l'application, pour qu'il n'existe qu'une seule version de chaque document.

Contact : support@signes.xyz
